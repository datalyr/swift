# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the [Security tab](https://github.com/datalyr/swift/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem and the steps to reproduce it.

We reply to the report in the private advisory. We publish a fix and an advisory after the problem is fixed.

## Supported versions

We fix security problems in the newest release only.
